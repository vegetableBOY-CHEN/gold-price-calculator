# Gold Price Calculator - Frontend

Vue 3 + Vite + TypeScript 前端应用。

## 启动

```bash
npm install
npm run dev
```

访问 http://localhost:5173

## 环境变量

创建 `.env.local`：

```
VITE_API_BASE_URL=http://localhost:8000
```

## 目录说明

| 目录 | 说明 |
|------|------|
| `src/components/` | 可复用组件 |
| `src/views/` | 页面视图 |
| `src/stores/` | Pinia 状态管理 |
| `src/api/` | API 请求封装 |
| `src/types/` | TypeScript 类型定义 |
