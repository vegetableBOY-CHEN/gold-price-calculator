# 原型画布 Chrome 插件

一个无需构建即可使用的 Manifest V3 插件，用来直接编辑现有网页并快速制作原型。

## 安装

1. Chrome 地址栏打开 `chrome://extensions/`。
2. 打开右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本目录 `chrome-extension`。
5. 打开任意普通网页，刷新一次，然后点击插件图标选择“开启页面编辑”。

> Chrome 设置页、扩展商店、新标签页等受保护页面不允许插件注入。

## 使用

- 点击元素：选中并打开属性面板。
- 插入：新增文字、按钮、图片占位或容器；默认放在当前选中元素后面。
- 复制粘贴：使用工具栏按钮，或按 `Ctrl/Cmd + C`、`Ctrl/Cmd + V`。复制会将元素及全部后代的计算后样式内联，以尽量保持视觉一致。
- 拖动元素：第一次点击选中，再按住已选中的元素拖动；只有实际移动后才会记录修改。
- 缩放元素：拖动选框右下角的黄色手柄。
- 双击文字：直接编辑文案。
- 方向键：移动 1px；`Shift + 方向键` 移动 10px。
- `Ctrl/Cmd + Z`：撤销；`Ctrl/Cmd + Shift + Z`：重做。
- 删除键：隐藏选中元素。
- 导出：下载包含当前修改的完整 HTML。
- `Alt + Shift + E`：快速开启或关闭编辑器。

修改按完整页面 URL 保存在 Chrome 本地存储中，刷新页面后会自动恢复。

复制采用“冻结视觉样式”策略：插件会递归读取根元素和全部子元素的浏览器计算样式，并写入复制件的内联样式。因此即使复制件离开原有 CSS 父级环境，边距、字体、颜色、布局、边框、阴影等也能尽量保持一致。由脚本实时绘制的 `canvas` 内容以及依赖运行时状态的动画不属于普通 DOM 样式，无法保证完全复制。

## 更新插件后仍显示旧错误

Chrome 会保留旧版本扩展产生的错误，并且已打开网页中的 content script 不会被热替换。更新代码后请依次：

1. 在 `chrome://extensions/` 点击本插件的“重新加载”，确认版本显示为 `0.3.0`。
2. 打开插件的“错误”页面，点击“全部清除”。
3. 刷新需要编辑的目标网页（仅刷新扩展页不够）。
4. 重新开启编辑模式；只有此后重新出现的错误才属于当前版本。
