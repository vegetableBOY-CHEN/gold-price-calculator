# 金饰购买成本计算助手（Gold Price Calculator）

## 1. 项目简介

### 1.1 项目背景

目前国内各大黄金品牌（周大福、老凤祥、周生生、中国黄金等）每日金价不同，同时各门店对于旧金置换规则也存在较大差异，例如：

- 是否支持跨品牌置换
- 是否支持金条置换
- 是否要求增金
- 增金比例是多少
- 是否收取损耗
- 是否需要补工费
- 是否按新金价格还是旧金价格计算

消费者往往难以计算真实购买成本，容易多花几百甚至几千元。

因此开发一款金饰购买成本计算工具，帮助消费者选择最省钱的购买方案。

---

## 2. 产品目标

本系统用于帮助用户：

- 查看当天各品牌黄金价格
- 自定义输入黄金价格
- 输入购买方案
- 配置各门店置换规则
- 自动计算最终花费
- 自动计算最终克均价
- 对比不同购买方案，找出最优方案

# 3. 功能需求

## 3.1 黄金价格展示

### 功能描述

首页展示国内实时金价以及各品牌黄金价格。

### 展示内容

| 名称 | 内容 |
|------|------|
| 国内大盘金价 | 元/克 |
| 品牌名称 | 周大福、老凤祥等 |
| 饰品金价 | 元/克 |
| 金条价格 | 元/克（可选） |
| 更新时间 | xxxx-xx-xx xx:xx |

### 功能要求

支持：

- 自动获取（后续）
- 手动维护
- 用户自定义修改价格

---

## 3.2 用户输入

用户需要能够输入购买信息。

### 输入项

#### 新金

| 字段 | 类型 |
|------|------|
| 品牌 | 下拉框 |
| 金价 | 数值 |
| 重量(g) | 数值 |
| 工费 | 数值 |

#### 旧金

| 字段 | 类型 |
|------|------|
| 重量(g) | 数值 |
| 品牌 | 文本 |
| 是否金条 | 是/否 |

---

## 3.3 门店规则配置

不同门店规则不同，因此需要允许用户自由配置。

### 支持配置项

#### 是否支持

- [ ] 支持金条置换
- [ ] 支持跨品牌置换
- [ ] 支持旧饰品置换

---

#### 增金规则

例如：

> 必须增加20%

配置项：

| 字段 | 类型 |
|------|------|
| 是否要求增金 | bool |
| 增金比例 | % |

---

#### 损耗规则

支持：

- 固定克数
- 百分比

例如：

```
损耗：
0.3g

或

2%
```

---

#### 工费规则

支持：

- 固定工费
- 按克收费

例如：

```
50元

或

30元/g
```

---

#### 回收规则

支持：

- 按旧金重量
- 扣除损耗
- 按回收价
- 按饰品价

---

## 3.4 成本计算

根据输入内容自动计算。

### 输出结果

包括：

#### 新金总价

```
新金重量 × 金价
```

---

#### 工费

```
固定工费

或

按克工费
```

---

#### 旧金抵扣金额

根据规则自动计算。

例如：

```
旧金重量

↓

扣损耗

↓

可抵扣重量

↓

× 回收价
```

---

#### 最终补差金额

```
新金总价

+

工费

-

旧金抵扣
```

---

#### 克均价

重点展示：

```
最终花费

÷

新金重量
```

例如：

```
总花费：

6500元

购买：

10g

克均价：

650元/g
```

---

## 3.5 多方案比较（推荐）

支持创建多个方案。

例如：

| 方案 | 品牌 |
|------|------|
| 周大福 |
| 周生生 |
| 老凤祥 |
| 中国黄金 |

自动比较：

- 总花费
- 克均价
- 节省金额

最终推荐：

> 最优购买方案

---

## 3.6 门店规则模板

支持保存规则。

例如：

```
周大福

↓

要求增金20%

↓

支持跨品牌

↓

支持金条

↓

损耗0.2g

↓

工费30元/g
```

以后再次购买可直接选择。

支持：

- 新建模板
- 编辑模板
- 删除模板
